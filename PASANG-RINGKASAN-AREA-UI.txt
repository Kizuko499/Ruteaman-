RUTEAMAN SEKOLAH/KAMPUS — RINGKASAN AREA UI

Patch UI untuk source FULL sekolah/kampus yang terakhir dibagikan. Mengubah hanya partial ringkasan di beranda + menambahkan CSS scoped. Tidak menimpa layout patch bahasa/login, database, .env, controller, route, JS, vendor atau public/build.

PERUBAHAN
- Header ringkasan dengan ikon lokasi dan indikator buka/tutup yang jelas.
- Pemilih wilayah dan tombol Tampilkan area menjadi kontrol yang sejajar di desktop dan disusun vertikal di HP.
- Akses direktori kampus menjadi baris aksi tersendiri, bukan tumpukan link teks.
- Jumlah kondisi, kategori dan waktu pembaruan dikelompokkan dalam panel lembut.
- Petunjuk status dipisahkan dengan jarak dan pembatas; warna tetap mengikuti teal/krem RuteAman.
- Target sentuh >=44px, fokus keyboard terlihat, nama panjang dan banyak kategori tetap berada di kartu.

DATA / FITUR
GET pemilih sekolah/kampus, optgroup sekolah/kampus, nilai slug, link kategori, direktori kampus, bantuan dan semua data-* hook untuk refresh tetap dipertahankan. Angka/label aktual tetap dari backend, bukan nilai contoh preview. Buka/tutup native details dan perilaku mobile dari JS lama tetap berlaku. Kondisi 0 tidak dinyatakan aman. Peta otomatis dan bahasa di Pengaturan tidak disentuh.

PASANG
1. Backup resources/views/pages/home-featured.blade.php jika memiliki perubahan khusus.
2. Upload ZIP dan EXTRACT DI HOME CPANEL, tempat folder ruteaman dan public_html berada sejajar. Pilih overwrite. Jangan extract di dalam salah satu folder itu.
3. Pastikan file ada di public_html/css/home-area-summary-v1.css serta ruteaman/public/css/home-area-summary-v1.css. ZIP memakai file 644 / folder 755.
4. Jalankan:
   cd "$HOME/ruteaman"
   php artisan view:clear
   php artisan view:cache
5. Purge CDN/cache bila dipakai, lalu hard refresh beranda. CSS home-area-summary-v1.css?v=summary-ui-1 harus HTTP 200.

Tidak perlu npm build/composer/migrasi/seeding. View memakai URL versi tetap, bukan hash_file(), sehingga tidak membaca hash CSS dari disk saat render.

VALIDASI
16 tes integrasi kampus / 82 assertions serta 3 tes ringkasan / 14 assertions lulus. Template dikompilasi. Lima keadaan kartu dirender dari markup Blade aktual dan diperiksa visual: desktop, HP, 0 laporan, tertutup, nama panjang/banyak kategori. Tidak ada overflow horizontal, resource gagal, console error atau element terpotong dalam preview. Kontras teks dan batas input diperiksa. Preview menggunakan fixture lokal, bukan database produksi. Tidak mengklaim pengujian end-to-end AJAX di produksi; hook JS yang ada dipertahankan. Belum dipasang ke server Anda.

ROLLBACK
Pulihkan partial home-featured.blade.php dari backup, lalu view:clear dan view:cache. CSS tambahan boleh tetap ada jika tidak direferensikan; tidak mengubah database.
